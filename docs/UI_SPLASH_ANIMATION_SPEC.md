# JH GetWay branded splash animation

Use the supplied official JH GetWay logo only. Do not generate or substitute another logo.

On a cold launch, show the selected-theme background, animate **JH GetWay** upward from below the center, travel to a controlled upper position, return to the final center position with a restrained settle, then reveal **JH Soft Corporation**. Use one deliberate motion, approximately 2–2.5 seconds, followed by a smooth transition to Overview.

The splash must run once per cold launch, must not replay on ordinary resume, must respect reduced-motion preferences, must not block gateway service startup, and must not display fake progress. Light and dark themes, small screens, status/navigation bars, and accessibility labels require verification before release.
